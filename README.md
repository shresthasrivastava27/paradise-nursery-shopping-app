# Paradise Nursery Shopping Application

Paradise Nursery is a React e-commerce learning project for browsing houseplants and managing a shopping cart.

## Project details
- React with Vite
- Redux Toolkit for cart state
- React Router for Home, About Us, Plants, and Cart
- 18 unique houseplants grouped into three categories (6 per category)
- Add-to-cart, quantity changes, remove item, totals, checkout placeholder
- Dynamic cart item count

## Main files
- `src/App.jsx` - landing page and routes
- `src/App.css` - landing-page background image styling
- `src/pages/AboutUs.jsx` - company information
- `src/redux/CartSlice.jsx` - Redux shopping cart slice
- `src/components/ProductList.jsx` - product listing
- `src/components/CartItem.jsx` - shopping cart

## Run
```bash
npm install
npm run dev
```
